Online Learning · Methods note

Circular Block Bootstrap

An empirical uncertainty assessment for statistics computed from sequential data: resample short, ordered segments rather than individual observations.

Interactive · self-contained
01

Why blocks for online data?

In an online prediction stream, errors on nearby days can be dependent (e.g., weekday patterns or a demand surge). Ordinary i.i.d. bootstrap breaks their time ordering.

A block bootstrap samples contiguous runs with replacement, retaining local dependence within each block. “Circular” means that a block may cross the boundary from day n back to day 1.

03

How one bootstrap replicate is built

Sampling rule

Let Z1, …, Zn denote the recorded observations (or prediction-error records). Choose ℓ points per block and draw B independent bootstrap replicates, indexed by b ∈ {1,…,B}.

Sb,k ∼ Uniform{1,…,n},   k = 1,…,⌈n/ℓ⌉
Ib,k,j = 1 + ((Sb,k − 1 + j) mod n),   j = 0,…,ℓ−1

Block 𝓑b,k contains the ordered observations (ZIb,k,0, …, ZIb,k,ℓ−1). Concatenate the blocks, then truncate to n records. Repeat for b = 1,…,B.

04

What do we estimate? A 95% empirical interval

Example statistic: test-set RMSE

For recorded online forecasts ŷt and realized targets yt, keep the forecast–outcome pairs together. Define et = ŷt − yt, then:

T(Z1:n) = RMSE = √[ (1/n) ∑t=1n et2 ]

For each bootstrap draw b, evaluate T*(b) = √[ (1/n)∑i=1n eIi(b)2 ]. The online predictors are not retrained; this quantifies the sampling sensitivity of their recorded RMSE.

B = 1,000 resamples
Bootstrap distribution of T*(1), …, T*(B)
CI95%(T) = [ Q0.025(T*), Q0.975(T*) ]

The 2.5th and 97.5th percentiles of the B replicated RMSE values provide an approximate percentile bootstrap confidence interval for the performance statistic, subject to assumptions and block-length choice—not a prediction interval for the next day.

Limit: empirical is not automatically guaranteed

“95%” labels the bootstrap percentile cutoffs; it does not prove exact 95% frequentist coverage. Validity depends on the data-generating process and resampling assumptions (e.g., suitable stationarity/dependence and block size). In drifting online streams, those assumptions can fail.

For predictive coverage, see conformal prediction

Under exchangeability, standard conformal prediction constructs a set Cn+1(Xn+1) with finite-sample marginal coverage:

P{Yn+1 ∈ Cn+1(Xn+1)} ≥ 1 − α

This guarantee does not transfer unchanged to arbitrary dependent/nonstationary streams. Adaptive conformal methods study online and long-run coverage under distribution shift.
